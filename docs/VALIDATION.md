# Проверки и ограничения

2026-09-27. Стенд Ubuntu 24.04; Xray 26.3.27; Nginx 1.24; Certbot 5.8.0.

Проверено до установки бота:

- Xray TCP REALITY и XHTTP, подключение пользователя через Happ на Android подтверждено владельцем.
- Экспорты Mihomo проверены ядром 1.19.31, включая передачу трафика через контрольный SSH-туннель.
- Статическая подписка ТВ отвечает HTTPS200 с доверенным сертификатом на IP; неверный путь возвращает404.
- Сертификат обновляется через certbot renewal dry run; systemd timer активен.
- Обновление статической подписки через VPN разрешено отдельным правилом на порт9443.

Проверено после развёртывания бота:

- Telegram getMe подтверждает действующий бот, webhook отсутствует; systemd-служба активна.
- 8 unit-тестов: привязка и права владельца, одноразовые приглашения, истечение/отзыв, сохранение ручных пользователей, экспорт, миграция, идемпотентность update, rollback БД при ошибке применения.
- Временный пользователь действительно добавился в оба inbound Xray.
- Его обычная подписка и FlClash-подписка получены с HTTPS200, доверенным TLS и ожидаемыми параметрами.
- После удаления тестового пользователя URL вернул404, UUID исчез из обоих inbound.
- Ручные пользователи не изменились до и после проверки. Тестовый пользователь удалён.

В проверках нет отправки приглашений третьим лицам. Unit-тесты не содержат действующих секретов. Полноценную привязку владельца и импорт на устройстве завершает сам владелец.

Не подтверждено: конкретная модель Smart TV; устойчивость во всех сетях; работа именно при активных операторских белых списках; коммерческая нагрузка и платежи.
